# Rules for AI coding tools working in this repository

1. **The match data never goes to a hosted model.** The competition terms, quoted in the
   organisers' FAQ, forbid making the videos, datasets or any extracts of them available to
   a third-party hosted or cloud LLM. Work on the code only. Do not open, print, sample or
   summarise anything under `MTAH_DATA_DIR`. A person runs the pipeline and reports back
   pass or fail.
2. **Labels come from the algorithm.** No hand labels on this match, no hand corrections, no
   frame numbers of this match written into the code.
3. **No tuning on the public five minutes.** They check that the pipeline is correct; they
   do not choose between two versions of it (FAQ, EVALUATION.md).
4. **The submission must be regenerated byte for byte** by `python -m mtah run`. Keep the
   pipeline deterministic and change defaults only in `src/mtah/config.py`.
5. **No data in git.** `.gitignore` and `.githooks/pre-commit` enforce it; do not weaken them.
6. Run `python -m pytest` before every commit. Tests use synthetic data only.
